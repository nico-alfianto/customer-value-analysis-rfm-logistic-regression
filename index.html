Project Overview

Not all customers are created equal. This project answers two critical business questions: Which customers drive the most revenue? Can we predict high-value customers before they spend big?

Key Finding — Pareto Principle: High-value customers contribute 84.9% of total revenue, while only making up 33.3% of the customer base. Monetary value is the strongest predictor, followed by Frequency and Recency.

Methodology

End-to-end workflow following data science best practices.

1. Data Cleaning: Handle returns, missing CustomerID, outliers
2. RFM Analysis: Calculate Recency, Frequency, Monetary scores
3. Segmentation: Group into High, Mid, Low value tiers
4. Logistic Regression: Predict probability of being high-value
5. Business Action: Retention, Upsell, Reactivation strategies

RFM Calculation

Core logic used in the notebook and in the Playground above.

snapshot_date = df['InvoiceDate'].max() + timedelta(days=1)

rfm = df.groupby('CustomerID').agg({
  'InvoiceDate': lambda x: (snapshot_date - x.max()).days,
  'InvoiceNo': 'nunique',
  'Revenue': 'sum'
})
rfm.columns = ['Recency', 'Frequency', 'Monetary']

SQL Logic Example

How core RFM metrics are calculated in a relational database.

-- Calculate total revenue per customer
SELECT CustomerID, SUM(Quantity * UnitPrice) AS Revenue
FROM online_retail
GROUP BY CustomerID;

-- Segment customers using NTILE
SELECT *, NTILE(3) OVER (ORDER BY Revenue DESC) AS revenue_segment
FROM ( ... ) t;
